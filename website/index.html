Control the work.Keep the evidence.

Agent World is a Windows-native control room for coding-agent work. Its local ledger keeps intent and outcomes visible—even when reality is uncertain.

View source

Three operating principles

  1. 01

    Work leaves evidence.

    Receipts and immutable intent land before external action becomes visible.

  2. 02

    Parallel work needs answers.

    The surface stays organized around what is running, who needs you, and what changed.

  3. 03

    Proof is a sequence.

    Unknown outcomes become indeterminate. They are never replayed automatically.

Architecture

Durable before action.

Agent World separates recorded intent from execution, then compares the result with Git and provider reality. If the evidence is incomplete or contradictory, the state stays visibly unresolved.

  1. 01 Intent

    Persist the command receipt and immutable worktree plan.

    SQLite event log
  2. 02 Execution

    Run native Git or one bounded Codex final-result turn.

    Verified worktree
  3. 03 Verification

    Compare path, branch, HEAD, common directory, and provider lifecycle.

    Reality check
  4. 04 Evidence

    Record completed, failed, or indeterminate—never a guessed success.

    Durable outcome

Proven in source and fixtures

Durable core
One SQLite writer, idempotent receipts, bounded queues, and restart reconciliation.
Conservative Git
Worktree intent is recorded first; path, branch, HEAD, and common directory are verified after.
Bounded Codex path
Exactly Codex CLI 0.146.0, at most one active turn globally, prompt over stdin, durable session correlation, and no automatic replay.

Open evidence gates

Windows enforcement
No authenticated model turn—or authoritative real-Windows sandbox, read-scope, network, process-tree, or reopened-SQLite proof—has been run for promotion.
Authority boundary
Broad read, no write. The worktree is not a host-secret boundary; the prompt and model-selected readable context go to the configured Codex service. apply_patch may remain model-visible while writes are denied and detected.
Broader lifecycle
Claude, streaming, approvals, interrupt, resume, fork, edit workflow, review, merge, signed install, and updates remain gated.
