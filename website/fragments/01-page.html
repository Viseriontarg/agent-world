Boring where it matters

Built around failure invariants.

The product is not the animation. The product is what remains true after a crash, a retry, or a conflicting Git state.

A

Intent is durable before action.

Worktree plans and command receipts are committed before Git runs. A restart can tell what was decided before deciding what comes next.

receipt → immutable plan → side effect → verify
B

Replay is explicit.

The same command ID and payload returns the original receipt. A changed payload with the same ID is rejected as a caller bug.

same ID + same payload = same result
C

Uncertainty is a state.

A mismatch becomes indeterminate. Agent World does not reset, prune, delete, or force its way through ambiguous Git state.

mismatch ≠ permission to repair
